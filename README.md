# 💡 Lamp Login

A login page where the lamp actually works.

**Live:** https://YOURUSERNAME.github.io/lamp-login/

## Features
- Pull the cord - light on/off
- Click input - lamp turns on
- Username 3+ chars
- Valid email check
- Password 6+ chars
- Google & GitHub buttons
- Dark / light mode

## Files
- index.html
- style.css
- script.js

## How to run
Just open index.html - no install needed.
